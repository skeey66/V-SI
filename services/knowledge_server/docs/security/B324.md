# B324 hashlib 의 취약한 해시

## 위험
`hashlib.md5()`/`sha1()` 을 보안 용도로 썼다 (B303 과 같은 문제).

## 고치는 방법
`hashlib.sha256()` 으로 바꾸거나, 체크섬 등 비보안 용도면 `hashlib.md5(data, usedforsecurity=False)`.

## 예시
```python
digest = hashlib.sha256(data).hexdigest()
```
