# B303 취약한 해시 (MD5/SHA1)

## 위험
MD5·SHA1 은 충돌 공격이 가능해 무결성·비밀번호 용도로 안전하지 않다.

## 고치는 방법
무결성은 `hashlib.sha256`, 비밀번호는 `hashlib.scrypt` 나 `pbkdf2_hmac` 에 솔트를 쓴다. 보안 목적이 아니면 `usedforsecurity=False` 를 명시한다.

## 예시
```python
hashlib.pbkdf2_hmac('sha256', pw.encode(), salt, 200_000)
```
