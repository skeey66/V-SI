경계가 깨끗한지 검증하는 질문
  • 에이전트는 다른 에이전트를 아는가? → 모릅니다. AgentExecutor는 입력 Artifact만 받고 출력 Artifact만 냅니다. 스텁↔LLM 교체가 오케스트레이터에 무영향인 이유입니다.
  • 오케스트레이터는 Task 내부 상태를 아는가? → 모릅니다. SDK TaskStore 소관이고, 오케스트레이터는 푸시로 받는 완료/실패 통지만 봅니다.
  • UI가 죽으면? → outbox에 계속 쌓이고, 게이트웨이가 올라오면 이어서 테일합니다. 워크플로는 영향 없음.
  • Artifact 테이블은 누구 것인가? → 오케스트레이터. SDK의 Task 테이블과 다른 스키마라 한 트랜잭션에 묶을 수 있습니다.
