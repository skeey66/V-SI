# 비밀번호 저장·비교

## 위험
md5·sha1 은 비밀번호 저장에 부적합(빠른 무차별 대입).

## 이렇게 구현
`hashlib.pbkdf2_hmac('sha256', pw.encode(), salt, 200_000)` 또는 `hashlib.scrypt` 에 무작위 솔트(`secrets.token_bytes(16)`). 비교는 `hmac.compare_digest`. 요구사항이 md5 를 고집하면 `hashlib.md5(data, usedforsecurity=False)` 로 '보안 용도 아님'을 명시한다.
