# B605 os.system / os.popen

## 위험
`os.system(f'cat {name}')` 은 셸을 거쳐 명령 주입이 가능하다.

## 고치는 방법
`subprocess.run([...])` 리스트 인자로 바꾸거나 파이썬 파일 API 로 대체한다.

## 예시
```python
with open(name, encoding='utf-8') as f:
    text = f.read()
```
