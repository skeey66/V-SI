# B603 subprocess 호출 (shell 없음)

## 위험
shell 없이 실행해도 실행 파일·인자를 외부 입력으로 정하면 위험하다.

## 고치는 방법
실행 파일은 고정하고, 입력값을 검증하고(허용 목록), 가능하면 파이썬으로 대체한다.

## 예시
```python
if name not in ALLOWED: raise ValueError(name)
```
