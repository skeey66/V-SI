# B102 exec 사용

## 위험
문자열을 코드로 실행하는 `exec()` 는 입력이 섞이면 임의 코드 실행으로 이어진다.

## 고치는 방법
실행할 동작을 함수나 딕셔너리 디스패치로 미리 정의하고 이름으로 고른다. 수식 계산이 목적이면 `ast` 로 파싱해 허용한 노드만 평가한다.

## 예시
```python
ops = {'add': operator.add, 'sub': operator.sub}
result = ops[name](a, b)
```
