# B602 shell=True 로 명령 실행

## 위험
`subprocess.run(cmd, shell=True)` 에 사용자 입력이 섞이면 `; rm -rf /` 같은 명령 주입이 가능하다.

## 고치는 방법
`shell=True` 를 빼고 인자를 리스트로 넘긴다. 사용자 입력은 리스트의 한 원소로만 들어가게 한다. 가능하면 외부 명령 대신 파이썬 표준 라이브러리로 처리한다.

## 예시
```python
subprocess.run(['wc', '-l', filename], check=True, capture_output=True, text=True)
```
