# B608 문자열로 조립한 SQL

## 위험
`f"SELECT * FROM users WHERE name = '{name}'"` 처럼 SQL 을 문자열로 만들면 SQL 주입이 가능하다.

## 고치는 방법
DB 드라이버의 파라미터 바인딩을 쓴다. 테이블·컬럼 이름이 동적이면 허용 목록으로 검증한다.

## 예시
```python
cur.execute('SELECT * FROM users WHERE name = ?', (name,))
```
