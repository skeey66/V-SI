# 함수·클래스 이름이 다름

## 증상
`ImportError: cannot import name 'calc_total' from 'cart'`.

## 원인
모듈은 있지만 테스트가 기대하는 이름의 함수가 없다. 명세와 다른 이름으로 구현했다.

## 고치는 방법
테스트가 import 하는 이름 그대로 함수를 정의한다. 다른 이름을 쓰고 싶으면 별칭(`calc_total = calculate_total`)을 둔다.
