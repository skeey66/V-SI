# 다른 종류의 예외가 발생

## 증상
테스트는 `ValueError` 를 기대했는데 `ZeroDivisionError`·`KeyError`·`IndexError` 가 났다.

## 원인
입력 검사 없이 계산하다가 파이썬 기본 예외가 먼저 터졌다.

## 고치는 방법
계산 전에 빈 입력·0·없는 키를 검사해 명세의 예외로 바꿔 던진다.
