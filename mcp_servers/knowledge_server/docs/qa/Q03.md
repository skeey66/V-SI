# 인자 개수·이름이 다름

## 증상
`TypeError: f() takes 1 positional argument but 2 were given` 또는 `unexpected keyword argument`.

## 원인
함수 시그니처가 테스트 호출 방식과 다르다.

## 고치는 방법
테스트의 호출부를 그대로 보고 매개변수 순서·이름·기본값을 맞춘다. 키워드 인자로 부르면 같은 이름이어야 한다.
