# 구현 모듈을 찾지 못함

## 증상
`ModuleNotFoundError: No module named 'cart'` — 테스트가 import 하는 모듈 파일이 없다.

## 원인
구현 파일 이름이 테스트의 `from cart import ...` 와 다르다 (예: `your_module.py`, `Cart.py`).

## 고치는 방법
테스트 파일 맨 위의 import 문을 읽고 **정확히 그 이름**으로 구현 파일을 만든다. 대소문자도 같아야 한다.
